# File: effect.txt
#
# This file is used to initialize the special effect tile graphics for Sil.
#
# === Understanding effect.txt ===
#
# N: index : effect name
# G: ascii char : color
# T: tile row : tile column
#
# 'N' indicates the beginning of an entry. The index is the effect ID
#     used internally (0-255). The name is for documentation only.
#
# 'G' is for pseudo/ascii graphics. The char is the glyph to use when not
#     rendering tiles, and the color is one of the standard color letters.
#
# 'T' is for tile graphics - the row and column in the tileset atlas.
#     Values are decimal 0-63.
