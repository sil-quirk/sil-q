# File: vault.txt
#
# This file is used to create the "lib/data/vault.raw" file, which is
# used to initialize the "vault template" information for Sil.
#
# Do not modify this file unless you know exactly what you are doing,
# unless you wish to risk possible system crashes and broken savefiles.
#
#
# === Understanding vault.txt ===
#
# N: serial number : vault name
# X: room type : depth : rarity : rows : columns
# C: color (optional, 0-255, 0 means use depth default)
# F: flag1 | flag2 | flag3 ...
# D: lines giving full layout of vault using symbols below
#
# 'N' indicates the beginning of an entry. The serial number must
#     increase for each new vault.
#
# 'X' is for extra information - room type, minimum depth, rarity,
#     and optionally maximum depth.
#     Format: X:type:min_depth:rarity[:max_depth]
#
#     The max_depth parameter is optional (defaults to 0 = no limit).
#     If specified, the vault will only appear at depths <= max_depth.
#
#     type 10 - Gates of Angband
#     type 6  - interesting room
#     type 7  - lesser vault
#     type 8  - greater vault
#     type 9  - Morgoth's vault
#
# 'C' is for the wall color (optional). Color values 0-255, where 0
#     means use the default depth-based color. Common colors:
#     1=white, 2=slate, 3=orange, 4=red, 5=green, 6=blue, 7=umber
#
# 'S' is for optional style weights for this vault. Provide one or more
#     tokens of the form "styleIndex:weight" separated by spaces. Use "*"
#     for the styleIndex to mean "use this level's exact chosen style".
#     Examples:  S:*:8 50:2 51:2   or   S:*:10
#     If 'S' is omitted, defaults for this depth (from style-levels.txt U:)
#     are used; otherwise the vault's list is used verbatim.
#
# 'M' is for a unique entry message shown when the player first enters
#     the vault. It follows the same message/banner setting rules as
#     partition banners.
#
# 'F' is for the vault flags (if any)
#
#     TEST        - must be generated when choosing a vault (for debugging)
#     NO_ROTATION - must not be rotated when placing in the dungeon
#     TRAPS       - has twice the normal proportion of traps
#     WEBS        - has a 5% chance of a web per empty square
#     LIGHT       - 100% chance of being permanently lit
#     SURFACE     - generated more seldom in deeper dungeons
#
# 'D' lines describe the layout of the vault. Lines must be padded
#     with spaces to fill the dimensions specified. Vaults are described
#     with the following symbols:
#
#     $ - outside of the vault, where corridors may be connected
#     # - granite
#     % - quartz vein
#     : - rubble
#     , - sunlight
#     ; - glyph of warding
#     > - down stairs
#     < - up stairs
#     + - visible door
#     s - secret door
#     ^ - trap (50% chance -- use sparingly as there is already a TRAPS flag)
#     0 - forge
#     7 - chasm
#     1 - monster +1 level
#     2 - monster +2 levels
#     3 - monster +3 levels
#     4 - monster +4 levels
#     * - treasure +1 to +4 levels
#     & - treasure +1 to +4 levels (good)
#     ! - treasure +1 to +4 levels (great; high artefact chance)
#     ~ - a chest with +4 levels
#     S - an elf skeleton
#     h - a human skeleton
#     e - an orc skeleton
#     w - a web
#     ? - a monster +1 level and/or an item +1 level
#     @ - easterling spy
#     H - silent watcher
#     o - orc champion
#     O - orc captain
#     P - Valar Projection
#     z - thrall
#     Z - orc thrallmaster
#     f - cat warrior
#     F - cat assassin
#     t - troll +1d4 levels
#     T - troll guard
#     W - barrow wight
#     a - archer +1 level (any monster that shoots arrows)
#     b - flier +1 level (any monster that flies)
#     c - wolf +1d4 levels
#     v - vampire +1d4 levels
#     g - wight/wraith +1d4 levels
#     r - raukar +1d4 levels
#     M - spider +1d4 levels
#     d - dragon +4 levels
#     y - young cold-drake
#     Y - young fire-drake
#     I - flying cold-drake
#     J - flying fire-drake
#     A - Aldor
#     R - Gothmog
#     U - Ungoliant
#     D - Glaurung
#     K - Ancalagon the Black
#     G - Gorthaur
#     V - Morgoth
#     C - Carcharoth
#     N - Mandos
#     u - Durin’s Armor
#

# Future Vault Thoughts
#
# Ways to add more variety to the vault format:
#
#   Using a symbol such that one of that symbol becomes a secret door
#   e.g.
#
#   N:81:Ringway 2
#   X:6:5:8:10:14
#   D:$$$$$$$$$$$$
#   D:$..........$
#   D:$......?...$
#   D:$..#ssss#..$
#   D:$.?s.*.2s..$
#   D:$..s....s..$
#   D:$..#ssss#..$
#   D:$..........$
#   D:$...?......$
#   D:$$$$$$$$$$$$
#
#   maybe have lines:
#   O:y:33
#   M:u:42
#   T:):23
#
#   (or O:y:Mail Corslet)
#
#   for object, monster, terrain, with a symbol and then this is overridden in the map
#   so that it represents the index listed. One issue is things at a coarse grained level
#   currently: chest, archer, flier, wolf, vampire, raukar, spider, dragon
#
